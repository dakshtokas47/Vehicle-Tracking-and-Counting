## PROJECT NAME
**AI-Driven Vehicle Tracking and Counting System**

## PROJECT SCOPE
This project utilizes Computer Vision and Deep Learning techniques to automate traffic monitoring. By leveraging the YOLO (You Only Look Once) framework and OpenCV, the application processes video feeds in real-time to identify various vehicle types (cars, trucks, bikes), assign them unique persistent tracking IDs, and maintain an active count of traffic volume. This technology serves as a foundation for intelligent traffic management systems and smart city planning.
